C'était une image externe pointant sur /assets/images/icons/send.svg, dont le tracé est noir, redressé par un `filter: invert(1)` en CSS pour paraître blanc. Une image externe ne peut pas lire `currentColor` : l'icône restait donc blanche quand le texte du bouton passait à l'encre sombre au survol (`.btn--solid:hover { color: var(--accent-ink) }`). Le libellé changeait de couleur, l'icône non. En ligne avec `stroke="currentColor"`, elle suit le texte dans tous les états, et le `filter: invert(1)` disparaît avec elle. `1em` comme la flèche : l'icône suit la taille du texte au lieu de la fixer. {% endcomment %}
